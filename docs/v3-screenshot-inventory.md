## Required new captures

The P3 content and release review should source current, sanitized captures for:

1. Asset hierarchy and device detail
2. Live and historical telemetry
3. Process state and transition history
4. Alarm and notification workflow
5. Command request and execution status
6. Manufacturing/OEE dashboard
7. Process simulation and replay
8. Nova Edge Agent fleet, workload, health, metrics, and logs views

For each capture, record the product version, tenant/data source, owner, crop,
caption, alt text, redactions, and approval date. Use synthetic or explicitly
approved data; remove customer names, device identifiers, hostnames, addresses,
credentials, tokens, internal URLs, and commercially sensitive metrics.
