--- layout: v3 permalink: /iot-device-management/ title: Device & Asset Management description: Manage industrial devices, channels, reusable profiles, live data, hierarchy, status, and configuration in one operational workspace. summary: Give every connected machine, gateway, meter, controller, and sensor a durable identity, reusable data model, place in the asset hierarchy, and direct path to live and historical data. eyebrow: Platform capability theme: platform noindex: true sitemap: false content_sections: - eyebrow: Device registry heading: Build an equipment model that mirrors the real plant paragraphs: - Nova Vector does not treat connected equipment as an anonymous stream of measurements. Each device is registered with an identity, ownership group, status, profile, metadata, and parent relationship so the platform can represent sites, areas, lines, machines, gateways, meters, sensors, and other assets in a practical hierarchy. - That structure becomes the operating context for everything that follows. Live data, alerts, tasks, production records, dashboards, and integration logic can all refer back to the same registered equipment instead of maintaining parallel naming schemes in different applications. image: /assets/img/v3/features/02-devices-and-live-data/devices-tree.png image_alt: Nova Vector device tree showing hierarchical equipment relationships caption: The device tree organizes equipment by site and parent-child relationship rather than as a flat list. - eyebrow: Reusable profiles heading: Describe a device type once, then apply it consistently paragraphs: - Device profiles define the measurements and properties that give raw protocol data meaning. A profile can describe metric names, engineering units, data types, ranges, sampling behavior, protocol registers or objects, report-by-exception defaults, custom properties, and payload-decoding logic. - Profiles are versioned, can move through lifecycle states, and can be exported or imported. That makes them useful for repeated deployments of the same meter, PLC interface, machine family, or gateway without rebuilding the data model for every instance. image: /assets/img/v3/features/02-devices-and-live-data/profile-metrics.png image_alt: Nova Vector device profile metric configuration caption: Profile metrics define how measurements are named, typed, ranged, and interpreted. - eyebrow: Industrial connectivity heading: Keep protocol configuration attached to the equipment it serves paragraphs: - Nova Vector supports direct industrial connectivity for current platform adapters such as OPC UA, Modbus TCP, BACnet/IP, and SNMP, together with IoT transports including MQTT, HTTP, and WebSocket. CoAP and LoRaWAN are pilot capabilities and should be treated accordingly in project scoping. - Connection definitions and device profiles keep protocol-specific details close to the relevant equipment model. This reduces the gap between a register address or protocol object and the operational quantity users eventually see in dashboards and reports. image: /assets/img/v3/features/01-device-connectivity/protocol-catalog.png image_alt: Nova Vector industrial and IoT protocol catalog caption: The protocol catalog provides the connection paths used by directly connected equipment and gateways. - eyebrow: Live and historical data heading: Move from a device record directly into its operating history paragraphs: - The device page combines identity and configuration with current and historical measurements. Users can inspect incoming readings, filter by metric or channel, switch chart styles, adjust the time window, and open richer Grafana-based views when deeper analysis is needed. - Historical readings are stored as time series and remain available to reporting, APIs, process simulation, and other downstream workflows. The important distinction is that the data does not lose the equipment and profile context that explains what each signal represents. image: /assets/img/v3/features/02-devices-and-live-data/device-live-data.png image_alt: Nova Vector device live-data page caption: Live readings and history are available from the device record without switching to a separate monitoring application. related: - label: Real-Time Data url: /iot-timeseries-analytics/ - label: Platform Architecture url: /architecture/ - label: Integrations url: /integrations/ ---
