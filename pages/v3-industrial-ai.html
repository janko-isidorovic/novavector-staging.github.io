--- layout: v3 permalink: /edge-ai-industrial-iot/ title: Industrial AI & Edge Inference description: Use contextualized operational data, a preview on-premises AI assistant, and approved ONNX models for governed inference on Nova Edge nodes. summary: Prepare industrial data for external analytics and model development, then deploy approved models for local inference without presenting Nova Vector as a full training or MLOps platform. eyebrow: AI-ready by design theme: edge noindex: true sitemap: false content_sections: - eyebrow: AI-ready data heading: Start with context before asking a model to interpret operations paragraphs: - Nova Vector keeps measurements tied to devices, assets, process state, alerts, tasks, and manufacturing records. That context matters because a model trained on isolated sensor values often lacks the information needed to distinguish one operating mode, product, shift, or machine condition from another. - APIs and messaging interfaces can supply this governed operational data to external notebooks, analytics systems, and model-development environments. Model training and broader MLOps remain outside Nova Vector today. image: /assets/img/v3/features/03-dashboards-and-reports/home-dashboard.png image_alt: Nova Vector operational dashboard showing contextualized industrial data caption: Operational context is built before model deployment so AI results can be related back to real equipment and workflows. - eyebrow: Model governance heading: Register and approve model versions before they reach edge nodes paragraphs: - Edge AI uses the ONNX model format. Model versions are stored in the platform and can move through an approval process before deployment. Signing is available, and checksums are always verified, giving the deployment workflow a defined artifact to evaluate rather than an arbitrary file copied manually to the node. - Approval is currently role-based rather than a two-person approval process, and model signing is available but not enabled by default. Those are important current-scope details when designing a governance process around the feature. image: /assets/img/v3/features/08-edge-ai/model-approval.png image_alt: Nova Vector Edge AI model approval interface caption: Model versions can be reviewed and approved before they become deployment candidates. - eyebrow: Edge inference heading: Run approved models next to the live EdgeX data paragraphs: - A deployment selects compatible edge nodes and binds model inputs to EdgeX device readings. The Edge AI runtime performs inference locally and can continue operating without a cloud connection once the required model and runtime are present on the node. - Numeric and camera-model outputs can be returned to Nova Vector as ordinary device data. That allows results to appear in the same telemetry environment used by dashboards, reporting, automation, and other operational workflows. image: /assets/img/v3/features/08-edge-ai/deployment-board.png image_alt: Nova Vector Edge AI deployment board caption: Edge AI deployment status remains visible across the selected nodes. - eyebrow: Results heading: Treat inference output as operational data, not as a separate AI application paragraphs: - Returning inference results through the normal data path makes them easier to combine with existing asset and process context. A numeric anomaly score or classification can be stored and visualized next to the measurements that produced it. - The current implementation still has boundaries. Model-result alerts are configured per project, the platform does not yet show the node's measured inference latency and throughput, and switching a deployment off does not currently undeploy the model from nodes. image: /assets/img/v3/features/08-edge-ai/numeric-results.png image_alt: Numeric Edge AI inference results in Nova Vector caption: Inference results are returned as platform telemetry so they can be viewed with other operational data. - eyebrow: AI Assistant preview heading: Use a local language model for supported platform questions and actions paragraphs: - The AI Assistant is a separate preview capability. Its language model runs on an Ollama server inside or alongside the customer deployment, while the assistant uses the signed-in user's platform access when calling supported APIs. - For selected create, change, or delete operations, the assistant shows a confirmation step before the action is submitted. Its scope depends on the tool set currently exposed to the assistant and should not be described as unrestricted natural-language control of the platform. image: /assets/img/v3/features/09-ai-assistant/confirm-create.png image_alt: Nova Vector AI Assistant confirming a create operation caption: The preview assistant requests confirmation before selected write operations. related: - label: Industrial Edge Management url: /industrial-edge-management/ - label: Time-Series Analytics url: /iot-timeseries-analytics/ - label: Platform Architecture url: /architecture/ ---
