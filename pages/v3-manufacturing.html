A work order carries the product, target quantity, dates, priority, and related production context. The shift planning board then places approved work onto the appropriate line and shift so supervisors have a practical operating plan for the day. - Validated product speeds and planned stoppages contribute to expected capacity. As production runs, the same order can be updated with actual good, scrap, and rework quantities from machine signals and operator input. image: /assets/img/v3/features/06-manufacturing-operations/shift-planning-board.png image_alt: Nova Vector manufacturing shift planning board caption: The planning board places work orders onto production lines and shifts before execution. - eyebrow: Production execution heading: Compare the plan with what the line is producing now paragraphs: - Live machine signals can update work-order production while the shift is still active. Supervisors can see the current order and production context rather than waiting for end-of-day reporting to discover that the line fell behind. - This connection between machine data and work-order records is what allows plan attainment, production counts, stoppages, and quality quantities to be investigated together instead of as unrelated metrics. image: /assets/img/v3/features/06-manufacturing-operations/work-order-production.png image_alt: Nova Vector work-order production view caption: Work-order production connects current output with the order and production context responsible for it. - eyebrow: Recipes and routings heading: Define what a product should consume and how it should be made paragraphs: - Versioned recipes describe required materials, while routings describe process steps and operations. Alternatives can be represented where the manufacturing process allows substitution or more than one valid path. - During execution, actual material, labor, machine time, or energy use can be recorded against the work order. Standard-versus-actual comparisons then show quantity and cost variance in the context of the specific production order. image: /assets/img/v3/features/06-manufacturing-operations/recipe.png image_alt: Nova Vector manufacturing recipe caption: Versioned recipes define the bill of material used as the standard for production and consumption comparison. - eyebrow: Consumption heading: Make material variance visible while the production record is still intact paragraphs: - Consumption records connect input lots and actual usage to the plan and work order that consumed them. That makes it possible to compare the expected recipe quantity with what was actually recorded on the shop floor. - Project-specific connections to scales, ERP, or other shop-floor systems can extend this workflow, but those integrations are implemented according to the customer's environment rather than assumed to be universal built-in connectors. image: /assets/img/v3/features/06-manufacturing-operations/plan-consumption.png image_alt: Nova Vector manufacturing plan consumption caption: Consumption views compare expected and actual material use within the production plan. - eyebrow: Downtime and workforce heading: Explain lost production with both machine state and human context paragraphs: - Nova Vector can detect stoppages from machine state and let operators classify causes that signals alone cannot identify reliably. Those events support downtime frequency, duration, recurrence, OEE, MTTR, and MTBF analysis by line, machine, shift, or period. - RFID can add attendance and operator association where that hardware is part of the project. Support requests and response timestamps can then relate equipment events to the people involved in restoring production. image: /assets/img/v3/features/04-alerts-notifications-and-tasks/task-details.png image_alt: Nova Vector operational task details caption: Operational tasks can preserve the equipment and response context associated with a production issue. related: - label: OEE & Downtime url: /manufacturing-oee-software/ - label: Device & Asset Management url: /iot-device-management/ - label: Industrial Edge url: /edge-computing-platform/ ---
