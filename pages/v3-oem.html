Reusable profiles describe the metrics and properties common to a machine family, while each installed instance retains its own identity and ownership context. - The feature sources support this device-and-profile model directly. They do not define a packaged OEM portal or a universal multi-customer SaaS product, so customer separation and service experience should be designed for the specific OEM program. image: /assets/img/v3/features/02-devices-and-live-data/devices-tree.png image_alt: Nova Vector hierarchical device registry caption: Hierarchical device relationships can represent customer sites and installed equipment without flattening the installed base. - eyebrow: Remote evidence heading: Give service teams history before they decide to travel paragraphs: - Current and historical device data, alerts, operating state, and tasks can provide evidence about what a machine was doing before and during a reported problem. That gives service teams more context than a phone description or a single current-value snapshot. - The same data can be exposed through customer-specific dashboards or external applications using the documented APIs, depending on how the OEM wants to package the service experience. image: /assets/img/v3/features/02-devices-and-live-data/device-live-data.png image_alt: Nova Vector device live and historical data caption: Device history gives support teams a direct view of the measurements associated with the installed asset. - eyebrow: Edge software heading: Manage approved site-side software as part of the connected product paragraphs: - Where an OEM solution requires local device services or processing, Nova Edge can host approved workloads next to the machine. Node types, software bundles, rollout controls, and local operator access provide a managed path for maintaining that site-side stack. - Fleet management is currently an integrated beta capability, so it should be introduced through controlled deployments rather than described as a fully mature generic fleet-management service. image: /assets/img/v3/features/07-edge-management/rollout-board.png image_alt: Nova Vector edge software rollout board caption: Approved edge software can be rolled out to managed nodes with visible deployment state. - eyebrow: Product integration heading: Connect the OEM service model through APIs instead of database coupling paragraphs: - External customer applications, service portals, ERP systems, or engineering tools can integrate through documented platform APIs and supported messaging paths.
