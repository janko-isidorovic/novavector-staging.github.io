# Temporary Source Staging

The `tmp/` folder is a temporary staging area for Nova Vector website source materials.

Use this folder to upload documents, screenshots, images, and other reference files that need to be reviewed or incorporated into the website.

Files placed here may be used to:

- update website copy and product content;
- select or prepare screenshots and images for website pages;
- verify feature descriptions and technical claims;
- organize source assets before moving approved files into their permanent locations under the website's asset structure.

## Important

- Preserve the original folder structure when uploading source packages whenever possible.
- Files in `tmp/` should be treated as working source material, not permanent public website assets.
- Once an image or document has been reviewed and selected for use, it should be moved or copied to the appropriate permanent location in the repository.
- Temporary or superseded source files can be removed from this folder after the website update is complete.
